# Muse X04G

让 Xiaomi X04G 小爱触屏音箱成为 Muse AI 语音伙伴。

- **独立连接 Muse**：配对后通过音箱 Wi-Fi 直接连接，手机无需持续在线。
- **按键语音对话**：按住中间键讲话、松开发送，支持随时打断回复并开始下一轮对话。
- **自然语音与字幕**：Gemini TTS 搭配 Leda 音色，流式播放回复，同时显示字幕。
- **全屏动态角色**：适配 800×480 屏幕，支持半身特写、语音口型同步和回答后的卖萌动画。
- **触摸互动**：摸摸头触发笑脸、爱心与跳跃反馈，轻触屏幕即可打断语音。
- **柔和边缘流光**：说话时亮起彩色光晕，随声音平滑呼吸，支持开关和屏幕圆角校准。
- **便捷调节**：屏幕左侧上下滑动调亮度，右侧调音量，长按右上角打开设置。
- **开机即用**：自动启动、断网重连、进程异常恢复，配对信息在更新和重启后保留。
- **保留原系统**：沿用原有 Android、内核与驱动，支持双音量键长按返回 Android 桌面。
